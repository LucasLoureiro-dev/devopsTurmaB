# 🚀 DevOps Turma B

Projeto desenvolvido durante as atividades da **Turma B**, com o objetivo de praticar conceitos de desenvolvimento, versionamento e colaboração utilizando **Git e GitHub**.

## 📋 Sobre o projeto

Este repositório faz parte das atividades práticas da Turma B.

O projeto contém uma página HTML simples utilizada para aplicar conceitos de desenvolvimento e manutenção de código, além de práticas de colaboração através do GitHub.

## 🛠️ Tecnologias utilizadas

* HTML5
* Git
* GitHub

## 📁 Estrutura do projeto

```text
devopsTurmaB/
├── .github/
│   └── Template de Pull Request.md
├── index.html
└── README.md
```

## ▶️ Como executar o projeto

Como o projeto utiliza HTML puro, não é necessário instalar dependências ou configurar um servidor.

### 1. Clone o repositório

```bash
git clone https://github.com/LucasLoureiro-dev/devopsTurmaB.git
```

### 2. Acesse a pasta

```bash
cd devopsTurmaB
```

### 3. Execute o projeto

Abra o arquivo `index.html` diretamente no navegador.

## 🌱 Fluxo de desenvolvimento

Para contribuir com o projeto, recomenda-se utilizar branches para organizar as alterações:

```bash
git checkout -b feature/minha-alteracao
```

Após realizar as alterações:

```bash
git add .
git commit -m "feat: adiciona nova alteração"
git push origin feature/minha-alteracao
```

Depois, abra um **Pull Request** para revisão.

## 🔀 Pull Requests

O projeto possui um template de Pull Request dentro da pasta `.github`, com o objetivo de padronizar as contribuições e facilitar o processo de revisão do código.

Ao abrir um PR, procure informar:

* O que foi alterado;
* Por que a alteração foi realizada;
* Como testar;
* Evidências da alteração, quando necessário;
* Observações importantes para o reviewer.

## 🎯 Objetivos de aprendizado

Este projeto busca praticar:

* Versionamento de código com Git;
* Utilização do GitHub;
* Criação e organização de branches;
* Commits padronizados;
* Pull Requests;
* Code Review;
* Organização e documentação de projetos.
